# Leandro Sinatra — Portfolio Design Studies (Wave 4 Spatial Paradigms + Waves 1–3 Archive)

Sixteen interactive portfolio prototypes built with Leandro Sinatra's 19 real photographs (`Arbeiten/*.webp`) and Swiss High German (`de-CH`) copy.

Live preview via GitHub Pages: **https://itsleoiso.github.io/gptsp.github.com/**

## Wave 4 — Radically Non-Webpage Spatial Paradigms (`13`–`16`)
Zero top navbars, zero 3-tab page switchers, zero vertical document sections, zero footers, and zero modal lightboxes:

13. **[13 — Weltfeld (Infinite 2D Spatial Canvas)](concept-13-spatial-canvas.html)** — Boundless 2D pan-and-zoom photographic universe with cursor-anchored zoom, camera glide directly into uncropped plates, live SVG radar minimap, and an eastward `Archiv · 100` meridian.
14. **[14 — Tiefenraum (3D Z-Axis Depth Flight)](concept-14-depth-corridor.html)** — True CSS 3D perspective tunnel where wheel/touch propels the camera forward through Z-space (`0 m → 5700 m`) past floating plates with dynamic zone glow and a right-edge depth altimeter.
15. **[15 — Zweischnitt (Counter-Scrolling Split Diptych)](concept-15-diptych-engine.html)** — Two full-bleed circular opposing reels (Left glides up while Right glides down) separated by a draggable vermilion seam (`8%`–`92%`), forming 81 live diptych pairings.
16. **[16 — Blende (Full-Bleed Radial Light Continuum)](concept-16-radial-continuum.html)** — One continuous edge-to-edge living frame ordered around a rotatable `360°` tactile aperture dial by measured colour temperature, with adaptive room atmosphere and distraction-free *Ruhemodus*.
