# Leandro Sinatra — Portfolio Design Studies (Wave 5 Jungle + Wave 4 Spatial + Waves 1–3 Archive)

Eighteen interactive portfolio prototypes built with Leandro Sinatra's 19 real photographs (`Arbeiten/*.webp`) and Swiss High German (`de-CH`) copy.

Live preview via GitHub Pages: **https://itsleoiso.github.io/gptsp.github.com/**

## Wave 5 — 90s UK Jungle Edition (`17`–`18`, Purely Visual & Silent, Non-Webpage)
17. **[17 — AKAI-168 (Atmospheric Jungle Visual Sampler)](concept-17-jungle-sampler.html)** — 1995 *Good Looking* / Akai S950 hardware sampler deck with 18 backlit rubber MPC pads, series bank soloing, silent 168 BPM Amen breakbeat oscilloscope, phosphor LCD studio flip, and a 10" acetate dubplate crate (`Archiv · 100`).
18. **[18 — KOOL-94.6 (Pirate Radio FM & Rave Flyer Deck)](concept-18-pirate-radio.html)** — 1993 London pirate radio receiver (`88.0–108.0 MHz`) with draggable analog FM tuning needle, silent visual RF static snow bursts, acid-lime & rave-magenta flyer stamps, CRT scanlines, and a CEEFAX `P.100` Teletext page.
