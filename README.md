# Leandro Sinatra — 8 Portfolio Design Studies (Loud & Quiet)

Eight interactive portfolio design prototypes built with Leandro Sinatra's 19 real photographs (`Arbeiten/*.webp`) and Swiss High German (`de-CH`) copy.

Live preview via GitHub Pages: **https://itsleoiso.github.io/gptsp.github.com/**

## Wave 2 — Laut & Anders (`05`–`08`)

5. **[05 — Plakat (Swiss Brutalist Poster)](concept-05-brutalist-poster.html)** — Monumental condensed poster typography, 2px raw borders, Signal Red (`#E0241A`) & Wanderweg Yellow (`#F2C400`), ticker marquee, and Negative invert mode.
6. **[06 — Monument (Avant-Garde Art Magazine)](concept-06-art-magazine.html)** — Overlapping magazine masthead cover and expressive chromatic spreads (Sicily Ochre, Jura Cobalt, Vallorbe Forest, Crimson) with dynamic per-series color worlds.
7. **[07 — Kinetik (Kinetic Stage & Reel)](concept-07-kinetic-stage.html)** — Full-bleed dark kinetic stage with Electric Vermilion (`#FF3B1F`), outline display type, hover clip-path wipe reveals, and a horizontal cinema reel.
8. **[08 — Ateliertisch (Tactile Spatial Scatter Wall)](concept-08-scatter-wall.html)** — Interactive studio desk with draggable taped photo prints, shuffle/scatter & snap-to-grid controls, category filters, and a 100-pin wall.
