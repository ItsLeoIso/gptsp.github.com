# Leandro Sinatra — 12 Portfolio Design Studies (3 Creative Waves)

Twelve interactive portfolio design prototypes built with Leandro Sinatra's 19 real photographs (`Arbeiten/*.webp`) and Swiss High German (`de-CH`) copy.

Live preview via GitHub Pages: **https://itsleoiso.github.io/gptsp.github.com/**

## Wave 3 — Neue Welten (`09`–`12`, Unconventional Cross-Disciplinary)

9. **[09 — Atlas (Swisstopo Expedition)](concept-09-swisstopo-atlas.html)** — Interactive topographic map plotting Swiss Jura, Three-Lakes & Sicily waypoints with real GPS coordinates and altitude sorting (`230 m` – `3357 m`).
10. **[10 — Diaprojektor D26 (Braun Hardware Deck)](concept-10-braun-projector.html)** — Tactile 1960s Dieter Rams / Braun slide projector interface with mechanical shutter blink, stepped slide-tray keys, auto-advance LED, and `5×5 cm` slide mounts.
11. **[11 — Sinatra OS 2.6 (Curatorial Desktop)](concept-11-retro-os.html)** — Multi-window retro-modern desktop workspace with clickable folders, draggable focus-stacked windows, live Lyss clock, and a 100-sector disk map.
12. **[12 — Ma · 間 (Japanese Horizontal Scroll)](concept-12-ma-zen-scroll.html)** — Washi-paper horizontal gallery corridor with wheel-to-horizontal glide, vertical margin typography (`writing-mode: vertical-rl`), vermilion *hanko* seals, and *kakemono* hanging scroll.
